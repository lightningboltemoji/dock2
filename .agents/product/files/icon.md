# The Finder tile's icon

The Finder tile wears Finder's icon until the user makes one of their own: one of Cairo's pictures — the palm
tree, the dog, the TV — white on a colour they choose, as a macOS icon of Liquid Glass.

- **Chosen in Settings → Files**: a grid of Cairo's pictures, Finder's own icon first, each drawn as the tile
  would wear it, like with like — flowers, trees, fruit, animals — and a colour well. The tile changes as
  either does.
- **Any colour**: the colour well's whole range, never a palette. Going back to Finder's own icon keeps the
  colour for the next picture.
- **Cairo's own pixels**: 59 of its pictures, chosen by eye — no arrows, no train, none of the circuit
  symbols but the resistor. At every tile size each of Cairo's pixels covers a whole number of the
  screen's, so a picture stays crisp; its size steps as the tile grows rather than following it smoothly. On
  the smallest tiles, with no room for a pixel apiece, it is scaled down.
- **Icon Composer's look.** The plate, its rim and its shading are Icon Composer's own, and the picture sits
  on it as Icon Composer draws a layer — white, with its shadow — so the tile reads as one of the dock's
  icons rather than a picture pasted on.
- **Open:** the system's icon style — Dark, Clear, Tinted — which Finder's icon follows. In Dark the picture
  takes the colour, on the system's dark plate; Clear and Tinted ignore the colour, as they do every app's.
  Until dock2 can read which style is chosen, the icon is Default's.

The label still says Files, and ⌥-click still opens Finder ([files](README.md#ways-in)).
