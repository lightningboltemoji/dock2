# Clipboard history

dock2 keeps what you copy, finds it from the field, and shows all of it in a view.

## What is kept

macOS sends no notice when the clipboard changes. dock2 checks the pasteboard's change count a few times a
second and reads the pasteboard when the count moves. One copy is one entry; copying the same thing again
moves it to the top.

Kept: plain and rich text, links, files (as references), images (up to a size cap), colours.

Never kept:

- anything marked concealed or transient — `org.nspasteboard.ConcealedType`, `TransientType`,
  `AutoGeneratedType`, the conventions password managers follow;
- anything copied while an ignored app is in front: password managers by default (1Password, Bitwarden,
  Passwords, Keychain Access), and whatever the user adds;
- anything over the size cap;
- putting an entry back on the clipboard: that moves it to the top instead. What dock2 copies for the user —
  Files' ⌘C, Copy Path, a plugin's copy not marked concealed — is kept like any copy, as dock2's.

## Where it lives

On this Mac only, never synced, and encrypted at rest with a key in the user's Keychain: other apps running
as the user can read dock2's files, but not its Keychain item. Entries are kept for 30 days by default
(**Open:** a cap on their number as well); a pinned entry stays until it is unpinned. Settings clears it
all.

## The system's pasteboard privacy

macOS lets the user decide, app by app, whether programmatic reads of the clipboard are allowed, asked about
or denied (`NSPasteboard.accessBehavior`). dock2 reads that setting. When reads would ask or be denied, the
history pauses — rather than raise an alert at every copy — and Settings says how to allow dock2.

## Finding it

- **From the field**: entries matching the query, by their text or file name, in the Clipboard section.
- **Clipboard History**, a command and, if the user sets one, a global shortcut: the whole history as a
  view, newest nearest the field — a row per entry, its title alone, and beside the list the selected
  entry's preview (its text, a thumbnail, a file's icon). Its source app, when it was copied and how much
  there is sit in one line along the preview's foot, which stays as the preview scrolls. Typing filters.

## Actions

| Keys | Does |
| --- | --- |
| ↩ | **Paste**: dismisses dock2 and pastes into the app that was in front. Sending the paste needs Accessibility; without it, ↩ copies and dock2 says "Copied — ⌘V to paste". |
| ⌘↩ | Copy. |
| ⌥↩ | Paste as plain text. |
| ⌘⌫ | **Delete**, without asking; the × at a row's end, under the pointer, does the same, and ⌘Z puts the entry back while the history is open. In search's Clipboard section ⌘⌫ edits the query, and Delete is ⌘⇧D. |
| ⌘K | Pin, Delete; Open, for a file or a link; Quick Look, for a file — what else the history holds stays sealed, and shows in the preview beside the list. |

## Settings

On or off — the first launch asks — how long entries are kept, the ignored apps, the global shortcut, paste
or copy on ↩, and clearing the history ([settings](settings.md)).
