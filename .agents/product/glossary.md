# Glossary

| Term | Meaning |
| --- | --- |
| **the dock** | dock2's dock. |
| **the system Dock** | Apple's, which dock2 hides while it runs. |
| **platter, tile, label, dot** | the dock's glass slab; one item on it; the name bubble over a tile; the running indicator under one — as in `IMPLEMENTATION.md`. |
| **the panel** | the glass above the dock: the field, and whatever has grown out of it. |
| **the field** | the search field at the bottom of the panel. It never moves while you type. |
| **resting** | dock2 without the keyboard: the dock on screen, or hidden by auto-hide. |
| **reveal** | the dock appearing because the pointer reached it. |
| **summon** | the dock and the field appearing because of the summon shortcut, ⌘space by default. |
| **dismiss** | dock2 giving the keyboard back and returning to resting. |
| **engaged** | summoned, or with a query typed or a view open. An engaged dock2 stays until it is dismissed. |
| **the dwell** | how long the pointer stays on a revealed dock before dock2 takes the keyboard. |
| **the typing guard** | the rule that a reveal does not take the keyboard just after a keystroke elsewhere. |
| **the ring** | keyboard focus on a tile. |
| **the echo** | the dock showing the selected result: the ring and the label on the result's tile. |
| **temporary tile** | the tile that stands in for a selected app that is not on the dock. |
| **number badges** | 1–9 over the first nine tiles while ⌘ is held. |
| **source** | something that answers queries: apps, commands, the clipboard, files, a plugin. |
| **section** | one source's results. Sections come in a fixed order. |
| **top hit** | the single best result, nearest the field, selected. |
| **learned pick** | a result dock2 remembers being chosen for a query, and puts first the next time. |
| **action** | something done to a result or a tile. ↩ runs the primary one, ⌘↩ the secondary, ⌘K lists them all. |
| **command** | a result that is an action of its own: Clipboard History, Settings, a plugin's Search Vault. |
| **view** | a screen that fills the panel at its fixed size: the clipboard history, a plugin's UI, a section shown in full. |
| **Files** | dock2's file browser: the view that stands in for Finder's windows. |
| **the path bar** | the field, in Files: the current folder as segments. |
| **the other tab** | Files' second tab, a chip at the end of the path bar. |
| **file access** | Full Disk Access, or the grants for Desktop, Documents and Downloads. |
| **takeover** | a system behaviour dock2 switches off while it runs, journaled and given back. |
| **plugin** | a WebAssembly module and a manifest that add commands, results, views or tiles. |
| **capability** | one thing outside itself a plugin may reach, granted by the user. |
