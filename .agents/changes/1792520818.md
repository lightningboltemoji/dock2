# The product, audited against the code

> Change `1792520818` — 2026-10-20

## Goal

A read-only audit compared every MVP sentence of `product/` with the code and found twelve places where
they differed beyond what "Not yet" admitted; earlier, the Files leftovers — problems on rows, the chip's
ring, the grid — were built but unseen. This change closes those, sees what it can on screen, and trims
`design/` to what is genuinely ahead.

## Implementation

**Files.** An operation's failure names its item (`FileProblem`, from `ItemError`); in view, it sits under
the name with its remedy — Allow Access… for EPERM without Full Disk Access, otherwise Show in Finder —
also first in ⌘K. Seen, the row first truncated the message to nothing useful in a 246pt column, so copy
failures now say "“locked.txt” can't be read." and the row grows to two lines and a button. The ring on the
other tab's chip sat at its minimum: a clone copies no bytes and copyfile reports none, so finished files'
sizes count now — which also fixed the banner's bar and the Finder tile's. The banner's half-second
recheck re-showed a job it was first told of even after it failed. Locked places wear a lock; inside, Allow
Access… asks again; the ask comes the first time Files opens without the grant. dock2's own "Show in
Finder" opens the folder in Finder while dock2 holds the file viewer, where a reveal would return to
Files.

**The keyboard and search.** ↩ on the ring and ⌘1–9 opened Finder.app for Finder's tile and nothing for a
plugin's; one `use` now serves clicks, the ring and numbers. A plugin's view arrives stripped of chords that
are dock2's (`PluginChord`). File results gained Copy, Show in Finder and ⌘Y Quick Look (a screen on the
stack); a result whose file vanishes dims, its folder watched.

**Display settings.** Reduce Motion was honoured by the field alone; now reshapes crossfade, the hidden dock
fades where it shows, Files' growth crossfades and the panel's glass fades. Reduce Transparency and Increase
Contrast were ignored; the glass's shapes, as one path, are filled solid or stroked. Development switches
for each, as for the appearance and for Full Disk Access, let every one be seen from a terminal.

**Settings.** Search (sources, plugins' order, excluded folders, learned picks, which keep their titles now)
and Shortcuts (every global one) were missing. A chord on one of dock2's keys says which; one macOS refuses
says so. A plugin's secure settings were written to `plugins.json`; they are its secrets now, under a
prefix its own effects are refused.

**Plugins and views.** Opening a file needed `files`, which the product says is always allowed in answer to
an action — but never a program, so apps, executables, scripts and bundles are refused. `clipboard.read` and
`files` grant nothing yet, and the product says so. Bitwarden's server stays a setting, not a form field,
since it is the host `network` reaches. Views gained tags in eight tints, a scrubber for Now Playing, a date
picker and a folder chooser; the grid scrolls, virtualised, with ⌘↩ and ⌘K; Settings shows plugins' icons and
authors.

**Mishap.** The key tool's dock2 interlock — no other app focused, dock2's element focused — passed with the
panel dismissed, since dock2's bare window still reports focus; an Escape reached Xcode's "Install
Required" dialog and pressed Quit. The interlock now also refuses when the focused element is the window.

## Observations

- Seen: the grid, a problem's row, the ring filling, the locks and the ask, all three display settings,
  Settings' new sections, tags. Unseen: Now Playing's scrubber (nothing played), a vanished result's dim,
  a remedy's button pressed, the Full Disk Access grant landing.
- Bold matched ranges stay a design item until Spotlight's rows are measured, which the key tool's refusal
  to type while Spotlight is up makes unsafe here.
- An app updated in place keeps its old icon: the catalog sees moves, not icon changes.
