# What an independent review of the capabilities found

> Change `1793767687` — 2026-11-03

## Goal

The seven capability steps (`1793764149` to `1793766656`) put new code on every boundary between an
untrusted plugin and the Mac. A reviewer was given that code and the product's rules, not my conclusions,
and asked for concrete defects. It found twelve. Two crashed dock2 by probe, one let a plugin speak to a
service as another plugin, and one let an update reach further without asking.

## Implementation

Each finding, fixed. Those a test can show are tested.

1. **`{"$date": 1e300}` trapped converting to `Int64`.** A date past what XPC holds is refused.
2. **`HostPort(setting:)` trapped on a port above 65535.** It rendered in the install sheet, so a manifest's
   default could crash it, and so could a value a user typed. `UInt16(exactly:)` now, nil past the range.
3. **An XPC key holding a NUL**, `"dock2.plugin\0x"`, reached `xpc_dictionary_set_value` cut short to
   `dock2.plugin`. Dictionary order then decided whether it overwrote dock2's word. A key with a NUL is
   refused. (A substring search finds a NUL even when a combining mark follows it: measured.)
4. **A setting's default widened reach silently.** The reach recorded `$server`, not what it holds, so an
   update could change the default under it without asking, and a default of `*` made `allowedHosts` reach
   any host. Now:
   - a `$setting` is reached with its default (`$server=https://…`), so a changed default asks;
   - a setting's value counts as a host only if it is a host name (`host(inSetting:)`), in `allowedHosts`
     and in dock2's lines alike;
   - a folder setting may have no default (`folderDefault`), since the product's folders are the user's to
     pick, and a default of `/` was a whole disk the user never chose.
5. **The rule against opening programs had holes.** Ghostty declares the Shell role for executables and is
   this Mac's handler for `.sh`. JavaLauncher runs a jar it views. `.configprofile`, `.provisionprofile` and
   `.jnlp` passed `isDocument`. `runsWhatItOpens` now reads the app's own `CFBundleDocumentTypes`: the
   Shell role, or a program, app or script type outside the Editor role. Measured on this Mac: Terminal,
   Ghostty, Script Editor and JavaLauncher run what they open; TextEdit and Xcode don't. Ghostty declares
   `sh` as Editor but runs it, which its Shell entry gives away. The rule applies to a named app, to a link's
   handler, and to a document's own handler. The install-time list (`Apps.runners`) gained JavaLauncher,
   ProfileHelper (it installs what it opens, and declares nothing that says so), Ghostty, Warp, kitty,
   Alacritty and WezTerm. The three document types are refused by name as well.
6. **Request-line injection in `LocalHTTP`**: the method went into the request line as given, and `"Host "`
   slipped past the headers dock2 writes itself. A method and a header's name must be HTTP tokens and a value
   must break no line (`HTTPSyntax`), checked for both kinds of request. Its test found that the existing
   line-break check compared `Character`s: `"\r\n"` is one, equal to neither half, so a CRLF passed. It
   checks scalars now.
7. **`URLSession.shared` was everyone's**: one plugin's cookies, cache and credentials went with another's
   requests to the same host. Each plugin has an ephemeral session of its own, kept across an idle unload and
   dropped with new code or removal.
8. **Unbounded memory.** A chunk-size or trailer line without its end grew without limit; it is now capped
   at 64 KiB, as a head is. A whole HTTPS answer is read through the same delegate as a streamed one
   (`ResponseReader`), cancelled past 16 MiB as `LocalHTTP`'s is.
9. **A watch in flight was not held.** A batch could pass the limit, a folder setting moving meanwhile was
   missed, and a stop could leave it attached. It is held from the effect, ended by a stop or revoke while it
   resolves. Its folder is checked against the folders granted now, once resolved.
10. **A FIFO in a granted folder blocked every plugin's files**, since the queue is shared. Reads and appends
    open with `O_NONBLOCK` and refuse what is not a regular file. File work that waited its turn past a
    revoke or stop does nothing (`Ended`).
11. **A stopped instance's effects still ran**: its `stopped`, or its last event's answer, came back after
    `endAll` and could hold new timers, processes or sockets. Effects are acted on only from the instance
    that is current.
12. **The rest.** A failed second `pipe()` leaked the first. A plugin runs at most eight commands at once
    (`processLimit`). A connection whose reached address cannot be read fails closed. Revoking `run` tells
    the plugin, under each command's request, as revoking `network` does a request.

The reviewer found `PathGuard` (probed: links out at any step, case, `..`, missing tails), `CommandGuard`,
`Disclaim`, `PluginResources` and the process signalling sound.

## Observations

- Finding 11 is fixed by reading the code, without a test: catching an instance's last answer after its stop
  is a race a test would only sometimes win.
- A server that sends trailer lines without end, each under the cap, keeps its request held until the plugin
  is stopped or `local-network` revoked: each line resets the idle timer.
- `runsWhatItOpens` trusts what an app declares. An app that runs files and declares only the Editor role
  for them, with no Shell entry, is caught only by the install-time list.
