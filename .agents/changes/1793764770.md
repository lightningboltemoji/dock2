# Capabilities by name, each with what it reaches and why

> Change `1793764770` — 2026-11-03

## Goal

The second step of the capabilities plan (`design/plugins.md`). A manifest's capabilities were a list of
names with `hosts` beside them, so nothing said why a plugin asked, and nothing but `network` could name what
it reached. The CLI decided whether an update asked again by comparing the strings Settings shows. A
plugin could not tell what it held, and an effect added to the protocol fell into `needs`' `default` and
asked for nothing.

## Implementation

**The manifest.** `capabilities` is an object keyed by capability (`PluginManifest.Capabilities`): a typed
optional field per capability, each holding its scope and its `reason`. The scopes are the ones the later
steps enforce: `network`'s hosts, `local-network`'s `host:port`s and sockets, `files`' folder settings and
`write`, `apps`' schemes and apps, `xpc`'s services with their teams, and `run`'s commands, each with a
program, fixed arguments and slots, or `"*"`. A dictionary of capability to an enum of scopes would have
read the same JSON, but every use would match a case to reach a host list. The typed fields keep that work
in `declaration(of:)`, the one switch that the reach, the reasons and the order are derived from.

Decoding refuses the list form (`capabilitiesAsList`, with an example of the object) and any name this dock2
does not know. `validate()` refuses a capability without a reason, and a scope naming what it cannot reach:
a host that is not a host name, a `$setting` that is not a text setting, a `local-network` address that is
not on this Mac or the local network by its spelling, a `files` entry that is not a folder setting, a scheme
that is always allowed (`http`, `https`) or `file`, an app that runs what it opens, an Apple service, a team
that is not ten characters, a program that is not an absolute path, an argument like `{file}` that is no
slot, a slot used twice, or a path slot with no folder setting for it to lie inside. `api` stays 1. The four
manifests, the SDK and the CLI moved with it.

**The reach.** `PluginManifest.Reach` holds each capability's scope as sets, without the reasons.
`beyond(agreed)` names the capabilities that were added or reach further: a host, socket, folder, scheme,
app, service or command added, writing turned on, or a command's program, arguments or team changed. A
reason reworded asks nothing, and neither does renaming a command's id. `dock2 plugin dev` asks on it in
place of comparing descriptions, and the sheet will too. It is `Codable`, so the reach agreed to can be kept.

**The gate.** `PluginEffect.needs` is an exhaustive switch with no `default`. The guards are in Core:

- `PathGuard` resolves a path with `realpath`. For a path not there yet, it resolves the deepest folder that
  is there and appends the rest. A link at the first missing step is refused, since a write would follow it
  out.
- `CommandGuard` (the design's `CommandLine`, which would shadow Swift's own in `main.swift`) fills a
  declared command's slots: one argument each, never starting with `-`, a path or folder inside one, and
  `{folder}` as the working directory. A `*` command takes the plugin's arguments as given, NULs aside.
- `HostPort` decides what is local: loopback, private and link-local addresses, `.local`, unqualified names.
- The lists: `Apps.runners`, and `XPC.Service.isApple`.

**What it holds, told.** `started` carries `granted`, and a `granted` event follows a change Settings makes,
only to a running instance and only when the set changed. `PluginChoices.defaults` revokes `run` when a
command takes any arguments, so the escape is off until switched on, as `query` is while results start off.

**dock2's lines** (`PluginManifest.lines`) name what is enforced, `$setting`s resolved or named by their
setting ("the server you set in Server"). A program is named by its full path, since `/opt/homebrew/bin/git`
and `/usr/bin/git` are not the same grant. A command whose slot reaches a folder the plugin may write gets
"— it can do anything you can", as `"*"` does.

## Observations

- `PathGuard` checks a path, and the effect then uses the path it resolved. A link swapped in between the
  check and the use, by another process, is not caught there. The `files` step opens the last step with
  `O_NOFOLLOW`.
- The runners list holds the four apps the product names, plus Shortcuts and iTerm2. Other terminals are not
  on it.
- A `$setting` host in `local-network` is checked for being local only when it is used. The `local-network`
  step checks the address the connection reached as well.
- `clipboard.read` still grants nothing: its effects are still to come.
