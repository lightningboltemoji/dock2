# The Files tile's own icon

> Change `1794559862` — 2026-11-13

## Goal

With Finder shown while it has a window open (`1794557908`), the Files tile still wore Finder's icon by default.
That put two Finder icons on the dock, one of which opened Files. Merging the two tiles had hidden the problem. The
Files tile needs a face of its own, and Finder's look should stay one choice away for anyone who wants it.

## Implementation

The Files tile's own icon (`AppDirectory.filesOwn`) is a white `folder.fill` on dock2's violet plate. That is how
dock2 draws its own icons among apps' — Clipboard History, the built-in commands — and the shell draws it through
`IconImages.plated` and hands it to `AppDirectory`, as it hands over the picture drawer. `NSWorkspace`'s folder icon
stands in if the plates are missing. It is the default, so nothing is written to the config.

Rejected: dock2's app icon. That icon stands for the app, as Settings, ⌘⇥ and About show it. On the first tile it
would read as "dock2" and promise search or Settings, not a file browser. A folder in dock2's colour says what the
tile opens and whose it is.

Finder's icon is a cell beside the own icon in the Files row's picker. It writes a new shape,
`files = { app = "com.apple.finder" }`: another app's own icon. A path into `Finder.app` would also have worked,
since its `Assets.car` holds one Icon Composer stack, `Finder`. But it would put a system bundle's insides into the
user's file, and it would be copied into `icons/` like any chosen file and stop following the system's icon. `{ app }`
resolves to the app's own icon through `NSWorkspace`, never what the file gives that app, so two entries pointing at
each other cannot loop. The reader takes any app; Settings offers it only on the Files row.

Verified in the `golden-gate-base` VM (macOS 27.2):

- **Captures beside an open Finder window:** light at tile size 48, and dark at 128. The folder and Finder's tile
  read as two things.
- **The picker:** the Files row showed the folder as its own icon, with the Finder cell after it.
- **Choosing Finder:** it wrote `files = { app = "com.apple.finder" }`, and the Files tile then wore Finder's icon,
  with no dot.

## Observations

- Only the Default icon style was seen, and only in the VM: a plated symbol does not follow Dark, Clear or Tinted,
  like the other plated icons (design's _Pictures in the other styles_).
- `{ app }` naming an app that isn't installed reads without a diagnostic and leaves the tile its own icon.
