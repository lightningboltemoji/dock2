## Implementation

were unreachable with a vault on screen. `ActionSet` is the one rule for the list and the grid: ↩ and ⌘↩

SDK's `Grid` gained `actions`. Plugin instances also stopped themselves after five quiet minutes, busy or
not — a mechanism the third audit had missed, so the host's sweep made two: the instance's is gone.

What dock2 copies for the user is kept, as dock2's: `files/operations.md` says history keeps copied files,
and `first-party.md` that concealment is what keeps a plugin's copy out; `clipboard.md`'s "dock2's own
writes" meant the put-back, and now says so. "Show all…" lists carry search's chords, the ⌥ alternates as
actions of their own, and a submenu as a list pushed when chosen (`ChoicesHost`). A folder macOS refused
after the user chose to be asked about each is closed, so Files locks it and search's note names it. The
first paste without Accessibility says why it is asked for, and a notice stays long enough to read it.
