# ⌃ in a global shortcut

> Change `1792644089` — 2026-10-21

## Goal

A clipboard shortcut recorded as ⌃⌘V showed as ⌃⌘V in Settings and registered without error, but pressing
it did nothing. ⌥⌘V, recorded the same way, worked.

## Implementation

`KeyChord.control` was `1 << 13`. Carbon's `controlKey` is `1 << 12`. Bit 13 is `rightShiftKey`, which
`Events.h` marks "Not supported on Mac OS X". The recorder and Settings' display both use that constant, so
the chord read back as ⌃⌘V. `RegisterEventHotKey` accepted ⌘ plus right shift plus V, a chord no keypress
makes. ⌘, ⇧ and ⌥ had Carbon's bits. Every ⌃ chord was broken this way, for summon as well as for the
clipboard. The constant is now `1 << 12`, and a test in `Dock2SystemTests` checks all four bits against
Carbon's `cmdKey`, `shiftKey`, `optionKey` and `controlKey`.

0.1.0 shipped with this, so `defaults` can already hold a ⌃ chord with bit 13 set (the user's own was
`modifiers = 8448`, `0x2100`). `KeyChord`'s decoder reads bit 13 as ⌃. Nothing has ever produced that bit
except this bug: AppKit's flags carry no handedness, `carbonModifiers` never sets it, and Carbon does not
support it. The repair happens on read, and the stored value is rewritten in the correct form the next time
the shortcut is set. A migration that rewrote `defaults` once at launch was rejected, because the decoder
would still have to know the old form to recognise it.

## Observations

- Not yet verified live. Only a real ⌃⌘V on the keyboard can verify it, because `dock2 debug key` goes
  into dock2's own event queue and never reaches Carbon's hot-key matching.
- Running the debug build in place of the installed app set the installed app's clipboard index aside (its
  key is in the Keychain, the build's is in a file). The index was empty and was moved back.
  `OBSERVING.md` now says so. An older `index-unreadable-1792569551.sealed` (14 KB, set aside at 00:59
  on 2026-10-21) is the history a debug build had kept before the installed app replaced it. It is
  sealed with `clipboard.key` and was left alone.
