# Clipboard history

> Change `1792501806` — 2026-10-20

## Goal

Roadmap step 8: keep what is copied, find it from the field, show it all in a view, paste it back.

## Implementation

**Privacy first, measured.** The SDK's `NSPasteboard.AccessBehavior` says a `.default` app raises an
alert on its first programmatic read; a process started from this terminal reports `.alwaysAllow`, so
testing raised none. The Keychain item would prompt every rebuilt ad-hoc build, so outside the bundle the
key is a file.

**Core decides on types, never contents.** `ClipboardPolicy` and `ClipHistory` are tested on markers,
ignored apps, the size cap, kind precedence, dedupe-to-top, pruning around pinned entries and matching
files by name. The store is tested for a round trip, for nothing readable on disk, a 0600 key file, and a
wrong key opening nothing; the watcher against a private pasteboard for its own writes and concealed
copies.

**A preview per selection.** A list with preview carried each item's detail up front; for the history
that would decrypt every entry to open the view, so `ViewHost.detail(for:)` lets a host give it when the
item is selected.

**The paste.** dock2's ⌘V first seemed lost: the probe app it was aimed at had no Edit menu, and ⌘V
reaches a text view only through one. With a menu, the posted event pastes. Verified: a string put on
the clipboard with `pbcopy` was captured, sealed (`Clipboard/<id>.sealed`, `index.sealed`), found by
"clipboard test" as the top hit with "Finder · 24 seconds ago", and ↩ from the probe in front pasted it
there 0.15 s after the probe's window took its keys back. Clipboard History showed both test entries
newest nearest the field with the full text, its asterisks literal; ⌘⇧D asked and deleted each, leaving
"Nothing copied yet". The test entries and the system clipboard were cleared afterwards.

## Observations

- With `.default` access the alert would come at the first copy after the history is turned on.
- Images were not copied in testing; their rows show a glyph rather than a thumbnail.
- The narrow list beside a preview truncated titles under the "Paste ↩" hint; rows narrower than 400 pt
  now leave it out, and only path subtitles truncate in the middle.
