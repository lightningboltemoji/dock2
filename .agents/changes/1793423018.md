# The open tile closes what it opened

> Change `1793423018` — 2026-10-30

## Goal

A click on the Finder tile opened Files, and a second click did nothing visible: `showFiles` found Files already on
top and focused it. The user asked for the second click to close Files.

## Implementation

The rule is the open tile's, not Finder's: the dock already knows which tile wears the caret (`open`, set from
`ViewsController.onTop`), so `DockController.use` sends `onCloseOpen` when the tile chosen is that one, and
`AppController` wires it to `InteractionController.popView`. Only Files names a tile today, so in practice it is
Finder's; a plugin's screen that names its tile later gets the same behaviour.

- **A pop, not a dismissal.** Files opened from nothing pops to a dismissal, as before; Files opened over a query
  pops back to the search with its query and rows. That is the stack's own rule for its last screen.
- **Whole, not Esc's first step.** Esc asks the screen to `cancel` first (Quick Look, a typed path, a search inside
  Files). The tile skips that and pops the screen: the click is about Files, not about what is open in it.
- **⌥ still opens Finder.** The check sits before the switch and skips ⌥, so ⌥-click on the open Finder tile opens
  Finder as it always did.
- **Every way of choosing a tile.** `use` serves clicks, ⌘1–9 and the ring's ↩, so ⌘1 toggles Files too. The ring
  is unreachable while a view is up (the view takes the arrows), so in practice it is the click and the number.
- **Not through `showFiles`.** `showFiles` also serves reveals, Show in Files and spring-loading, none of which
  should close Files; the toggle belongs at the tile.

Verified on the debug build with `dock2 debug click tile:1` and `debug key cmd+1`, reading the panel's body size
(960 × 520 for Files, 640 × 57 for the bare field) and the phase from `debug state`, with captures: from nothing,
open then closed with the dock left revealed under the pointer; over the query "ghost", Files then back to the
search, its 7 rows intact; ⌘1 twice, open then closed.

## Observations

- Not tested live: ⌥-click on the open Finder tile, which would bring Finder forward. The guard is one condition.
- A plugin view pushed over Files (a plugin tile clicked while Files shows) leaves Files below it; a Finder tile
  click then pushes the Files screen a second time, as it did before this change.
