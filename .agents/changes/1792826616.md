# Asking for Screen Recording in every run

> Change `1792826616` — 2026-10-24

## Goal

dock2 asked macOS for Screen Recording once ever, at the first minimised window, and remembered it in
`askedToRecordScreen`. The app is ad-hoc signed, so its designated requirement is its cdhash. Every
reinstall looks like a new app to TCC and loses the grant, but the flag lives in the defaults domain and
survives the reinstall, so the new build never asked. The debug build shares that domain, so it could set the
flag for the installed app as well. On this Mac the flag was set and `/Applications/Dock2.app` had no Screen
Recording row in TCC. tccd's log shows the installed app only preflighting (`authValue=1`, undecided) and
never making the request. With no request, macOS gave no prompt and System Settings did not list dock2.

## Implementation

The persisted key is gone. `DockController` keeps `askedToRecordScreen` for the run, so the first minimised
window matched without the grant calls `CGRequestScreenCaptureAccess` once per launch. macOS shows its
prompt only while the answer is undecided, so asking every run cannot nag someone who has already answered.
A fresh build is undecided again and gets asked.

Rejected: keying the flag to the build's cdhash or version. It would track what TCC tracks, but less
reliably, and TCC already makes the decision. Rejected: asking on every match. Once per run bounds the calls
to tccd without changing what anyone sees.

## Observations

- The prompt itself was not observed in a live run. The debug build inherits the terminal's grant, so it
  never asks. Seeing the prompt needs the built app, installed over the running one. Build and tests pass.
- An existing `askedToRecordScreen` in a user's defaults is no longer read and is left in place.
- Accessibility's ask at the first paste (`askedToPaste`) is still once ever, and a reinstall has the same
  problem there.
- The lasting fix for re-granting after a reinstall is a stable signing identity rather than ad-hoc; this
  change only makes sure dock2 asks again.
