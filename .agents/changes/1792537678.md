# Third audit: the product against the code

> Change `1792537678` — 2026-10-20

## Goal

A third pass of `product/` against the code found fifteen gaps, ten smaller ones and ten statements in
`IMPLEMENTATION.md` that described the code wrongly. Two were dangerous: while Files' path bar was edited,
⌘⌫ trashed the selected file and ⌘Z undid a file operation; and installing a plugin again — `dock2 plugin
dev` does at every rebuild — regranted all it declared and switched it back on.

## Implementation

**Files.** The path bar's field keeps the text keys while edited. ⌘F's walk passes over what
`FileAccess.asks` says would prompt, the grant probed once before it, not per folder. The Finder tile's
menu and the path bar share `Places`. Allow Access… on a row watches for the grant as the banner's does.

**Plugins.** `PluginChoices.declared` remembers what the manifest declared when the user last agreed;
`granting(_:)` is the one rule for an update and for first-party plugins after a dock2 update. `query`
follows the results switch rather than standing as a grant of its own. Idle instances unload by a sweep
each minute; "idle" excludes a tile on the dock, an open view (the delegate knows the stack), timers,
subscriptions and unanswered requests — Bitwarden's vault would otherwise lock behind the user's back.
A result's action leaves dock2 up: the plugin decides.

**Search.** A use is an opening, recorded where dock2 opens an app — so the dock's opens count — and a
command run. The system's counts became a `tiebreak` the session compares after the signal. Settings →
Search gained "Ranked first", which the spec named and nothing offered.

**Clipboard.** Every write dock2 makes goes through `OwnWrite`, which marks it with nspasteboard.org's
`org.nspasteboard.source`; the watcher skips dock2's and credits another app's marked copy to that app. A
colour's data is an `NSKeyedArchiver` archive — checked by writing one and decoding it — and previews as a
swatch. The Paused note reads `accessBehavior` itself. `data(for:)` opens only with the key held.

**Panel and menus.** Spotlight's growth was measured with a column captured by
`CGDisplayCreateImageForRect`, looked up by `dlsym` since Swift's SDK hides it: 57→467 pt in ~235 ms,
back in ~210 — dock2's slide. Tracing dock2's own showed the edge jumping while frames showed the glass
growing: the shadow was set to its final frame at once. The shadow and a reveal mask on the rows now move
explicitly from their presentation values with the glass (`Motion.animate`); traced again, the edge
climbs over ~230 ms. One `MenuBuilder` path draws every action menu with icons, chords (`Chord`) and
destructive red; an ⌥ alternate must share its item's key equivalent for AppKit to pair them, which
showing chords broke and was fixed on screen.

**Permissions.** Each protected folder's state, once the user chose to be asked, by `opendir` rather than
a listing; Files and Folders' anchor, `Privacy_FilesAndFolders`, opened once to check its title.

**A review of the batch.** Allow Access… on a row recorded Full Disk Access as the user's choice, so one who
had chosen the three folders lost them if they then granted nothing: it opens the pane and watches, and the
choice stands. `dock2 plugin dev`'s store wrote its stale choices back at each rebuild: `install` reads
them from disk first. Results' chords now pass `PluginChord` as views' do. The unanswered requests are a set
of ids, so a refusal no longer cancels another's count, a malformed URL is answered, and stopping clears it.

## Observations

- Idle unloading is 3 minutes, a starting value for the spec's open "a few minutes".
- The stand-in carrying on as the running tile is reasoned from the dock's diff, not seen.
- The Finder tile's progress look is still the guess the audit called it; measuring the system Dock's
  needs a download in progress on it.
- A ⌘⇧ chord is a result's own only while the search is on top; ⇧⌘Z falls through to the field's redo.
