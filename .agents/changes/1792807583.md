# No separator before the running apps

> Change `1792807583` — 2026-10-23

## Goal

dock2 drew a separator between the pinned apps and the running apps that are not pinned. The system Dock
has none there, and dock2 should not either.

## Implementation

Measured first: with Calculator open and not pinned (`show-recents` off), the hidden system Dock's
Accessibility list read Finder, Fiber, Ghostty, Calculator, a separator, Trash. That is the only separator,
and it sits before the Trash. Change `1792485673` had seen this and kept dock2's separator as a deliberate
difference. That decision is reversed here.

`DockModel.compose` appends the running apps straight after the pinned ones, and `DockGroup.running` is gone.
The number badges used `.separator(.running)` as a stand-in for every slot that is not a tile, a drag's
gap included. `DockModel.numbered` now takes `[TileKind?]`, so the controller passes `view.items.map(\.tileKind)`
and no stand-in is needed. The numbering test used to rely on the running apps' separator. It now gets its
separator from plugin tiles.

Observed live under `DOCK2_DEBUG=1` with Calculator open: Files, Fiber, Ghostty and Calculator sit 134 pt
apart with no separator slot between, and ⌘ held badges them 1–4.

## Observations

- With "Show suggested and recent apps in Dock" on, the system Dock puts a separator and a recents section
  after the pinned apps. dock2 has no recents section, and this change does not add one.
- Drag to pin never used the separator: it counts the pinned tiles on show, so it is unchanged.
