# Folders sort among the files by default, as in Finder

> Change `1794886432` — 2026-11-16

## Goal

Files put folders before files unless Settings said not. Finder's default mixes them, so in `/Applications` dock2
listed Utilities first, while Finder lists it under U among the apps. Neither app's setting had been changed.

In the `golden-gate-base` VM (macOS 27.2), with `_FXSortFoldersFirst` absent from `com.apple.finder`, Finder's column
for `Seek/a` lists `a-file.txt` above the folder `b`. That key is Finder's Settings → Advanced → "Keep folders on top:
In windows when sorting by name". It was absent on this Mac too.

## Implementation

- `files.folders-first` now defaults to `false`. Its help, which `config.example.toml` and Settings show, names the
  Finder option it mirrors. `make example` regenerated the example.
- `DirectoryListing.list`'s own `foldersFirst` default follows, so a caller that doesn't pass the setting gets
  Finder's order too. The one such caller, path completion, uses order only for which match's case a completion
  keeps.
- A config file holds only settings that differ from their defaults. Anyone who never touched the toggle gets the new
  order, and a `folders-first = true` line keeps the old one.
- Reading Finder's own key instead was considered. It would follow a Finder setting most people never see, and
  leave dock2's toggle with nothing to do. Matching the default keeps one setting, in dock2's own Settings.

## Observations

- Verified in the VM: `Seek/a` lists `a-file.txt` before `b`, as Finder does. Core, TOML and the listing's test pass.
- A package, `.app` included, was a file before this change and still is, so Utilities' place among the apps depends
  only on this default.
