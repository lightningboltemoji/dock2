# Pointer opens search

> Change `1794464688` — 2026-11-11

## Goal

The switch for reveal-to-type was `dock.type-to-search`, "Type to search when the dock appears". Taken literally
it describes typing, not the pointer, and someone wanting the pointer at the bottom edge to bring up the dock
without the field and the keyboard didn't recognise it as the switch they wanted.

## Implementation

The setting is `dock.pointer-opens-search`, `Settings.pointerOpensSearch`, labelled "Show search when the pointer
reaches the dock". It says "reaches" rather than "reveals" because without auto-hide the dock is always shown and
the pointer only arrives on it. The reducer keeps `revealToType`, the product's name for the behaviour, and the
defaults-domain import keeps reading `typeToSearch`, the name that domain used.

No migration: dock2 is pre-alpha. A file that still says `type-to-search` gets an unknown-setting diagnostic, and
the setting reads as on.

## Observations

- Tested by the unit tests and by `dock2 config` on a scratch `DOCK2_CONFIG`. The Settings window wasn't opened.
  The label is a string change, and the behaviour behind the switch didn't change.
